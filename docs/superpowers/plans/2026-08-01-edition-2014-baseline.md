# Перевод книги Торна на базу 2014 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Перевести 29 карточек заклинаний и спеку с базы «PHB 2024 там, где заклинание переиздано»
на базу «PHB 2014, а 2024 только там, где версии 2014 нет или она слабее».

**Architecture:** Механика заклинаний целиком живёт в данных (`src/data/content/thorne/spells/*.json`),
движок читает её обобщённо и ни одного заклинания по имени не знает — проверено grep'ом: идентификаторы
встречаются только в тестах и фикстурах. Поэтому смена редакции — это правка контента и спеки, а не кода.
Схема заклинания не меняется. Порядок работы задаёт [CLAUDE.md](../../../CLAUDE.md): сначала спека
(Задача 1), затем карточки, затем сводные таблицы и закрытие открытых вопросов.

**Tech Stack:** JSON-контент, Zod-схема `src/data/schemas/spell.ts`, Vitest, `scripts/check-docs.py`.

## Global Constraints

- **Правило из [CLAUDE.md](../../../CLAUDE.md): «Не выдумывать игровую механику».** Ни одно число, ни одна
  формулировка не пишется по памяти. Источник — страница заклинания на `dnd.su` (2014) или
  `next.dnd.su` (2024), прочитанная предложение за предложением.
- **Выжимкам поисковика не верить.** При сборе адресов сводка поиска утверждала, будто на 2014-й
  странице «Мерцания» стоит 1к6 на 4+. Это признак склейки с 2024-й страницей. Только `WebFetch`
  самой страницы, только дословное чтение.
- **Если страница не открылась** — поле остаётся как есть, карточка помечается невычитанной, задача
  останавливается и вопрос уходит в [open-questions.md](../../open-questions.md). Угадывать запрещено.
- **Язык:** контент, документация и интерфейс — русский; код, идентификаторы, сообщения коммитов — английский.
- **Названия на русском не меняются.** [OQ-18](../../open-questions.md) уже решил: «Поиск фамильяра» и
  «Незримый слуга» — названия игрока, они каноничны для проекта, хотя справочник в обеих редакциях
  пишет «Невидимый слуга». Трогать `nameRu` не нужно ни в одной задаче.
- **Значение `source`:** ровно строка `Player's Handbook (2014)` для карточек, переехавших на 2014.
  Тест проверяет поле только на непустоту (`content.test.ts:58`), формат ничем не валидируется —
  единообразие держится дисциплиной.
- **Один коммит — код и спека вместе.** Каждая задача заканчивается коммитом, в котором изменения
  контента и документации лежат рядом.

## Карта редакций

Решения игрока от 2026-08-01. Принцип: база 2014; 2024 остаётся там, где 2014 слабее или версии нет.

**На 2014 с правкой механики и текста — 14 карточек**

| Карточка | Что меняется по существу |
|---|---|
| Контрзаклинание | спасбросок Тел → авто-срыв ≤3 ур. и проверка характеристики КС 10+уровень для 4+; появляется повышение уровня |
| Отражения | d6 за двойника на попадании → d20 6+/8+/11+ на нацеливании, КД двойника 10+Лов |
| Превращение | временные хиты → цель принимает хиты формы, при 0 возврат с переносом лишнего урона |
| Поиск фамильяра | чувства бонусным действием → действием; облик из закрытого списка; компонент — уголь, благовония и травы |
| Невидимость | обрыв на «нанёс урон» снимается; остаётся атака или заклинание |
| Электрошок | отнимает все реакции, а не только Провоцированные атаки; возвращается преимущество по металлическим доспехам |
| Мерцание | кость броска (сверить: 2014 ожидается d20 на 11+) |
| Обнаружение магии | преграда деревом и землёй — 3 фута вместо 1 |
| Паутина | вырваться простой проверкой Силы, без Атлетики |
| Молния | добавляется поджог горючих предметов в области |
| Незримый слуга | размер силы не указывается |
| Гипнотический узор | компонент — блёстки или благовония вместо конфетти |
| Переносящая дверь | спутник обязан быть не больше размера заклинателя |
| Доспехи мага | заклинание можно окончить своим действием |

Рассеивание магии · Маскировка · Падение пёрышком · Починка · Туманный шаг · Луч холода · Щит.

## Самопроверка плана

**Покрытие решений.** Каждая из 18 карточек с расхождением закрыта задачей: Контрзаклинание (2),
Отражения (3), Превращение (4), Поиск фамильяра (5), Невидимость (6), Электрошок (7), Мерцание,
Обнаружение магии, Паутина, Молния (8), Незримый слуга, Гипнотический узор, Переносящая дверь,
Доспехи мага (9). Четыре карточки, остающиеся на 2024, не трогаются нигде, кроме Задачи 11, — это
намеренно. Семь совпадающих закрыты Задачей 10.

**Чего в плане нет намеренно.** Точных русских формулировок правил: они берутся со страниц справочника
в момент исполнения, а не пишутся заранее по памяти. Это не заглушка, а требование
[CLAUDE.md](../../../CLAUDE.md) — правило, восстановленное по памяти, в карточку попасть не может.
Взамен каждая задача несёт точный адрес страницы, точный список полей и точное описание ожидаемого
расхождения, чтобы исполнителю было с чем сверять.

**Риск.** Ожидание по «Мерцанию» противоречит сводке поисковика (Задача 8, Шаг 2). Это единственное
место, где сверка может отменить вывод анализа; порядок действий на такой случай в шаге описан.
