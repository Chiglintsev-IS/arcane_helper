# Arcane Helper

Оффлайн-помощник игрока-волшебника за столом D&D 5e (2014). Устанавливаемое веб-приложение для
iPhone, полностью работает без сети. Единственный персонаж — Торн, волшебник 7 уровня.

Приложение ведёт игрока через применение заклинания — выбрать, проверить возможность, объявить
мастеру, определить броски, потратить ячейку, отслеживать эффект — и держит всё, что для этого нужно
знать о персонаже: ячейки и источники магии, хиты и концентрацию, книгу, вещи, лист, ход боя. Правил
оно не выдумывает: числа берутся из правил D&D и справочников мастера; чего источник не даёт, того в
приложении нет. Каждое расходование ресурса записано в лог и обратимо.
