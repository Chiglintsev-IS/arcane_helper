# Глоссарий

Единый словарь проекта. Связывает русский термин (интерфейс и документация), английский оригинал
правил D&D 5e и имя в коде. **Имена в коде берутся только отсюда.** Если нужного термина нет —
сначала добавить строку сюда, потом использовать в коде.

Правило именования: русский — в интерфейсе и документации, английский `camelCase` — в коде,
`SCREAMING_SNAKE_CASE` — для констант и значений перечислений в данных.
