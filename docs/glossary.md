# Глоссарий

> Обновлено: 2026-08-03 · Статус: рабочий документ

Единый словарь проекта. Связывает русский термин (интерфейс и документация), английский оригинал
правил D&D 5e и имя в коде. **Имена в коде берутся только отсюда.** Если нужного термина нет —
сначала добавить строку сюда, потом использовать в коде.

Правило именования: русский — в интерфейсе и документации, английский `camelCase` — в коде,
`SCREAMING_SNAKE_CASE` — для констант и значений перечислений в данных.

| Перебивка | Override | `overrides` | Введённое руками значение производного числа. Пустая перебивка означает «по формуле» |

| Вдохновение | Inspiration | `inspiration` | Отметка мастера, тратится на преимущество |
| Базовый максимум хитов | Hit point maximum | `maximumBase` | Максимум с листа, до снижений |
| Снижение кровью | — | `bloodReduction` | Часть максимума, потраченная кровавым колдовством; возвращается по часу |

| Труднопроходимая местность | Difficult Terrain | — | Каждый фут перемещения по ней стоит дополнительный фут |
| Слабо заслонённая местность | Lightly Obscured | — | Помеха на проверки Мудрости (Восприятие), чтобы разглядеть что-то в области |

| Обследование облика | — | — | Не термин, а обычное действие: в редакции 2014 «Маскировку» разоблачают, потратив действие на обследование облика. Отдельного действия «Изучение» в 2014 нет — оно введено редакцией 2024 ([ADR-0020](decisions.md#adr-0020)) |
| Расследование | Investigation | — | Навык Интеллекта. В карточках — «проверка Интеллекта (Расследование)», не «проверка Анализа» |

| Ход | Turn | `turn` | Отрезок раунда, принадлежащий одному участнику |
| Кости хитов | Hit Dice | `hitDice` | По одной за уровень, размер задаёт класс — у волшебника d6. Тратятся коротким отдыхом, половина возвращается долгим ([FR-134](domains/vitality.md#fr-134)) |

| Магическое восстановление | Arcane Recovery | `applyArcaneRecovery`, `arcaneRecovery` | Особенность волшебника: после короткого отдыха вернуть ячейки суммарным уровнем до 4 (для 7 уровня) за день. ## Термины персонажа Торна

Механики его расы и подкласса. Они не входят в базовые правила, поэтому названия фиксируются здесь,
чтобы в коде и интерфейсе не появились варианты вроде «мана» или «кровь».

| Русский | English | Имя в коде | Значение в проекте |
|---|---|---|---|
| Лунный тролль | — | — | Самодельная раса Торна. Даёт регенерацию и кровавое колдовство, обе особенности подавляются огнём и солнцем |
| Кровавое колдовство | — | `bloodMagicAvailable` | Обмен хитов на очки заклинаний действием в свой ход |
| Очки заклинаний | Spell points | `spellPoints` | Второй способ оплатить сотворение вместо ячейки. Не путать с ячейками |
| Ступень возвышения | — | `ascensionTierRate` | Диапазон уровней, задающий курс обмена хитов на очки |
| Снижение максимума | — | `maximumReduction` | Урезание максимума хитов кровавым колдовством. Не лечится |
| Рана | — | `woundsFromExchange` | Следствие обмена до нуля хитов. Механика не определена — [OQ-16](open-questions.md#oq-16) |
| Троличья регенерация | — | `regenerationDue` | Восстановление хитов в начале своего хода ниже половины максимума |
| Подавление | — | `suppression` | Состояние, отключающее расовые особенности: урон огнём или прямой солнечный свет |
| Солнечное окаменение | — | — | Стадии от почасовых спасбросков под солнцем. Вне MVP |
| Создатель рун | Runecrafter | — | Подкласс волшебника из Unearthed Arcana |
| Руна | Rune | `runes` | Расходуемое применение особенности подкласса. Не заклинание и не ячейка |

## Термины продукта

|---|---|---|
| Режим экрана | `ScreenMode`, `SCREEN_MODES` | Одно из шести состояний экрана: «Игра» — `play`, «Книга» — `book`, «Журнал» — `journal`, «Лист» — `sheet`, «Сумка» — `bag`, «Привал» — `rest`. Определяет состав списка, шапки и операций ([FR-200](screens.md#fr-200)). Состояние интерфейса: его держит оболочка, в сохранение персонажа он не входит ([FR-204](screens.md#fr-204)) |

| Жест | `gesture` | Описание движения рук, посоха, мела |
| Визуальный эффект | `visualEffect` | Описание того, что видят окружающие |
| Вариант отыгрыша | `completeVariants` | Готовый связный текст. Категории: короткий, атмосферный, саркастический |
| Профиль отыгрыша | `RoleplayProfile` | Настройки тона, тем магии и запретов конкретного персонажа |
| Схема ритуала | `RitualDiagram` | Рисунок ритуала из слоёв, который игрок повторяет на бумаге. Не «знак»: это слово занято «Знаками ограждения» |
| Печать | `centralSeal` | Центральная фигура схемы ритуала: глаз, сфера, треугольник вызова, пустая рука |
| Надпись | `inscription` | Рунная надпись по обводу схемы, с переводом в `meaningRu` |
| Знак | `GlyphId`, `glyphs` | Элемент закрытого словаря схемы: руна, алхимический металл или стихия |
| Активный эффект | `ActiveEffect` | Продолжающееся следствие применённого заклинания либо ручной правки, требующее отслеживания |
| Ручной эффект | `startManualEffect` | Активный эффект без заклинания: статус, которого нет в каталоге. Заводится строкой ввода в блоке активных эффектов, снимается там же, где и любой активный эффект |
| Поправка к КД | `setArmorClassAdjustment`, `armorClassAdjustment`, `manualKind` | Ручной эффект второго вида — знакопеременный вклад в Класс Доспеха. Опознаётся типизированным признаком в данных эффекта, а не строкой имени. Заводится плиткой КД в шапке ресурсов: новое значение заменяет прежнее, ноль снимает поправку |
| Повторяемое действие | `repeatableAction` | Действие, доступное в последующие ходы благодаря активному эффекту |
| Заметка к заклинанию | `spellNotes`, `setSpellNote` | Домашнее правило или напоминание игрока. Игрового состояния не меняет и в журнал не попадает |
| Журнал боя | `journal`, `JournalEntry` | Последовательность событий изменения состояния. Основа отмены |
| Оболочка приложения | `PlayShell` | Корневой компонент: загружает сессию и направляет к одному из шести экранов по текущему режиму |
| Экран «Игра» | `GameScreen` | Заклинания текущего хода, шапка ресурсов, отметки схватки, действующие эффекты |
| Экран «Книга» | `BookScreen` | Полный состав книги заклинаний, подготовка, просмотр карточек |
| Экран «Лист» | `SheetScreen` | Характеристики, КД, навыки, перебивки, прочие прибавки |
| Экран «Сумка» | `BagScreen` | Вещи, доспех, деньги |
| Экран «Привал» | `RestScreen` | Короткий и долгий отдых, магическое восстановление, «Прошёл час» |
| Экран «Журнал» | `JournalScreen` | Записи журнала, отмена, обмен данными |
| Конец боя | `endCombat`, `combat_ended` | Отметка в журнале о том, что бой закончен. От неё считаются раунды и потраченное в ходу; восстановление здоровья — её следствие, а не она сама |
| Отмена последнего действия | `undoLast` | Обратная операция к последней записи журнала |
| Состояние персонажа | `CharacterState` | Полный набор изменяемых данных Торна |
| Сохранённая сессия | `PersistedSession` | Запись в хранилище: персонаж, журнал и каталог заклинаний вместе. Читается и пишется целиком ([ADR-0009](decisions.md#adr-0009)) |
| Каталог заклинаний | `spellCatalog` | Все карточки, по которым играет приложение. Не путать с книгой заклинаний: та — список известных идентификаторов внутри состояния персонажа |
| Встроенный каталог | `loadBuiltInCatalog`, `loadThorneSpells` | Карточки из сборки приложения. Действуют, пока игрок не загрузил свои, и в хранилище не попадают ([ADR-0019](decisions.md#adr-0019)). Первое имя — зависимость стора, второе — её реализация в контенте Торна |
| Источник каталога | `spellCatalogSource` | Чем играют прямо сейчас: `built_in` или `imported` |
| «Применить всё равно» | — | Продолжение сотворения вопреки предупреждению, поскольку мастер вправе разрешить исключение |
| «Мастер решил иначе» | — | Ручная корректировка состояния, расходящаяся с правилами |

## Термины, которых следует избегать

| Не использовать | Использовать | Почему |
|---|---|---|
| слот, ячейка магии, заряд | ячейка заклинания / `spellSlots` | Три синонима в одном коде ведут к рассинхрону |
| DC | КС | В интерфейсе весь текст русский |
| каст, кастовать | сотворение, сотворить | Документация и интерфейс без жаргона |
| бафф, дебафф | активный эффект | В правилах 5e таких категорий нет |
| фаербол | — | Огненная тематика вредна персонажу механически |
| мана, кровь как ресурс | очки заклинаний / `spellPoints` | «Мана» скрывает, что ресурс покупается хитами |
| скилл, стата | навык, характеристика | Единая терминология правил |
| книга заклинаний о наборе карточек | каталог заклинаний / `spellCatalog` | «Книга заклинаний» уже занята списком известных идентификаторов в `CharacterState`, и два смысла у одного слова рассинхронизируют код с документацией |
| привал, «Вне боя» (как название режима) | «Игра» / `play` | Режима для того, что делается вне боя, нет: это состояние «Игры», отмечаемое схваткой. Привалом остаётся называться только набор операций отдыха и восстановления — `CampActions` |
