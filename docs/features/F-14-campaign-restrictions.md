# F-14 — Ограничения кампании

> Статус: План · Этап: 2 · Обновлено: 2026-07-31
> Требования: FR-160…FR-162 · Источник: решения мастера и вид персонажа, добавлено спецификацией

## Зачем

Часть заклинаний Торну недоступна не по правилам класса, а по двум внешним причинам: огонь вреден
троллю, а некоторые заклинания мастер запретил как ломающие мир. Если просто не вносить их в контент,
через месяц никто не вспомнит, почему их нет, и кто-нибудь добросовестно «починит» пробел.

## Требования

<a id="fr-160"></a>
### FR-160 — Реестр запретов с причиной

**Статус:** План · **Проверка:** unit `bannedSpells`, скрипт проверки контента

Система должна хранить список запрещённых заклинаний, у каждого — причина запрета одной из категорий:
вред виду персонажа, решение мастера.

Запрет — данные, а не отсутствие записи: список правится без изменения кода
([content.md](../content.md#запрещённые-заклинания)).

<a id="fr-161"></a>
### FR-161 — Запрещённое заклинание не предлагается

**Статус:** План · **Проверка:** интеграционный `banned spell absent from all lists`

Запрещённое заклинание не должно попадать ни в книгу заклинаний, ни в списки подготовки, ни в
результаты фильтров, ни в экран реакций.

Это второе жёсткое ограничение приложения наряду с лимитом подготовки: принцип «предупреждение вместо
запрета» ([FR-031](F-03-cast-wizard.md#fr-031)) здесь не действует, потому что решение принято мастером
до боя, а не в бою.

<a id="fr-162"></a>
### FR-162 — Причина видна при поиске

**Статус:** План · **Проверка:** E2E `search shows ban reason`

Если пользователь ищет запрещённое заклинание по названию, система должна показать причину запрета
вместо пустого результата.

Пустой результат читается как потеря данных или поломка. Видимая причина отвечает на вопрос сразу и
за столом: «Понимание языков — запрещено мастером».

## Поведение и крайние случаи

**Огонь определяется по данным, а не по списку.** Заклинание с типом урона «огонь» запрещено
автоматически, без перечисления в реестре: перечислить всю огненную школу вручную нельзя, а пропущенное
заклинание — это ошибка в пользу опасного для персонажа выбора.

**Запрет мастера — только перечислением.** «Ломает мир» невозможно вывести из данных: это суждение о
кампании. Такие заклинания перечисляются поимённо с пометкой, что решение принял мастер.

**Запрет и особенность подкласса.** Особенность «Создателя рун» выдаёт «Понимание языков» бесплатно, а
мастер это заклинание запретил. Приложение показывает запрет и не предлагает применение; разрешение
противоречия — за мастером ([OQ-12](../open-questions.md#oq-12)).

**Отмена запрета.** Мастер вправе передумать. Снятие записи из реестра возвращает заклинание во все
списки без других правок — поэтому запрет и хранится данными.

**Запрет уже применённого заклинания.** Если заклинание запретили, пока его эффект активен, эффект
продолжается: запрет влияет на возможность сотворить, а не на уже сотворённое — как и снятие подготовки
в [F-09](F-09-preparation.md).

## Проверка

| Что проверяем | Как |
|---|---|
| Заклинание с уроном огнём запрещено без записи в реестре | Unit |
| Запрещённое отсутствует во всех списках | Интеграционный, по одному на список |
| Причина запрета видна при поиске | E2E |
| Снятие записи возвращает заклинание | Unit |
| Активный эффект не гаснет от нового запрета | Интеграционный |
