# F-08 — Активные эффекты

> Статус: План · Этап: 2 · Обновлено: 2026-07-31
> Требования: FR-090…FR-092 · Сценарии: [UC-01](../use-cases.md#uc-01), [UC-03](../use-cases.md#uc-03) · Источник: ТЗ §9.10

## Зачем

Применив заклинание, игрок переключается на другие дела и забывает, что эффект продолжается: что
паутина всё ещё держит область, что «Полёт» вот-вот истечёт, что «Размытие» даёт помеху атакующим.
Активный эффект — напоминание, живущее после закрытия карточки.

## Требования

<a id="fr-090"></a>
### FR-090 — Создание активного эффекта

**Статус:** План · **Проверка:** интеграционный `cast creates active effect`, [AC-14](../quality.md#критерии-приёмки-mvp)

После применения продолжительного заклинания система должна создавать активный эффект.

Активный эффект должен содержать: название; тип; время начала; длительность; признак концентрации;
повторяемое действие; условия завершения; пользовательскую заметку.

<a id="fr-091"></a>
### FR-091 — Ручное завершение

**Статус:** План · **Проверка:** E2E `end effect manually`

Пользователь должен иметь возможность вручную завершить эффект.

<a id="fr-092"></a>
### FR-092 — Повторяемое действие

**Статус:** План · **Проверка:** E2E `repeatable action button`

Для эффектов с повторяемым действием должна отображаться кнопка соответствующего действия.

Пример: активный «Огненный шар» отсутствует у Торна, но активная «Паутина» требует напоминания о
спасброске Ловкости для входящих в область существ, а «Полёт» — о том, что перемещение изменилось.

## Поведение и крайние случаи

**Длительность отслеживается вручную.** В MVP нет счётчика раундов и таймеров: эффект показывает
заявленную длительность («до 1 часа», «10 раундов») и время начала, но не отсчитывает их сам.
Автоматические таймеры отнесены в [следующие версии](../constraints.md#после-mvp). Причина — приложение
не знает о ходе боя ничего, кроме того, что отметил игрок, и ложный отсчёт хуже отсутствия отсчёта.

**Мгновенные заклинания эффектов не создают.** «Волшебная стрела» не оставляет записи: список
активных эффектов должен содержать только то, что действительно требует внимания. Иначе он
превращается в журнал и перестаёт читаться.

**Связь с концентрацией.** Эффект концентрационного заклинания помечен признаком концентрации и
закрывается автоматически при её потере ([FR-083](F-07-concentration.md#fr-083)). Обратное неверно:
неконцентрационные эффекты живут независимо.

**Условия завершения.** Хранятся текстом («до конца следующего хода», «пока цель не получит урон»),
поскольку формализовать все условия 5e в MVP невозможно. Текст показывается прямо в карточке эффекта —
это ответ на вопрос «когда это кончится», который игрок задаёт мастеру.

**Порядок списка.** Концентрационный эффект всегда первым, далее по времени начала. Концентрация —
самое хрупкое из активного, она должна быть на виду.

**Долгий отдых.** Закрывает эффекты с длительностью короче отдыха; эффекты «до рассеивания» и
подобные остаются, потому что 8 часов их не отменяют.

## Проверка

| Что проверяем | Как |
|---|---|
| Продолжительное заклинание создаёт эффект, мгновенное — нет | Интеграционный, по одному заклинанию каждого вида |
| Эффект виден после закрытия карточки заклинания | E2E, AC-14 |
| Потеря концентрации закрывает связанный эффект | Интеграционный |
| Ручное завершение отменяемо | Интеграционный через FR-111 |
| Кнопка повторяемого действия появляется только там, где оно есть | E2E |
| Порядок списка: концентрация первой | Unit на функции сортировки |
