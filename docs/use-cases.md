## UC-01

**Выбор заклинания во время своего хода**

Предусловие: идёт бой, ход Торна, есть неизрасходованное действие.

1. Пользователь открывает режим «Игра».
2. Выбирает фильтр «Действие».
3. Видит подготовленные заклинания, доступные действием.
4. Открывает карточку и читает краткий эффект.
5. Нажимает «Сотворить».
6. Выбирает уровень ячейки — шаг показывается, только когда выбор есть
   ([FR-021](scenarios.md#fr-021)).
7. Читает итоговый экран: объявление мастеру, инструкция и отыгрыш раздельными блоками.
8. Подтверждает применение.
9. Приложение расходует ячейку и запускает эффект.

Постусловие: ячейка списана, действие отмечено потраченным, при необходимости начата концентрация и
создан активный эффект, в журнале появилась запись.

Ключевая проверка: до шага 8 состояние персонажа не изменилось ([FR-022](scenarios.md#fr-022)).

## UC-02

**Использование реакции**

Предусловие: не ход Торна, реакция не израсходована.

1. В персонажа попадает атака или враг применяет заклинание.
2. Пользователь открывает «Реакции» кнопкой в ряду кнопок «Игры» ([FR-060](scenarios.md#fr-060)).
3. Приложение показывает подходящие реакции.
4. Пользователь выбирает реакцию.
5. Приложение показывает немедленный результат.
6. После подтверждения расходуется ячейка.
7. Реакция становится недоступной до начала следующего хода персонажа.

Постусловие: реакция отмечена потраченной до начала следующего хода персонажа, ячейка списана (если
реакция её требует), запись в журнале.

Ключевая проверка: путь от триггера до результата занимает не более двух нажатий
([M-02](product.md#метрики)).

## UC-03

**Запуск концентрации при уже активной концентрации**

Предусловие: активна концентрация на заклинании A.

1. Пользователь выбирает концентрационное заклинание B.
2. Приложение проверяет текущую концентрацию.
3. Выводится предупреждение с названием текущего эффекта и последствиями его завершения.
4. Пользователь подтверждает замену.
5. Эффект заклинания A завершается.
6. Эффект заклинания B появляется в блоке активных эффектов.

Постусловие: активна ровно одна концентрация — на B; эффект A закрыт с причиной «заменена
концентрация»; в журнале две связанные записи.

Альтернативный ход: на шаге 4 пользователь отменяет — ячейка не расходуется, эффект A продолжается.

## UC-04

**Получение урона при концентрации**

1. Пользователь отмечает получение урона и вводит его величину.
2. Приложение вычисляет КС проверки концентрации.
3. Приложение показывает:

   ```text
   Проверка Телосложения
   КС: 10
   Модификатор: +N
   ```

4. Пользователь отмечает успех или провал.
5. При провале концентрация завершается, активный эффект закрывается.

КС проверки — 10 или половина полученного урона, что больше. Бросок совершает пользователь
физическим кубиком: приложение не бросает кубики в MVP.

## UC-05

**Долгий отдых**

1. Пользователь открывает режим «Привал» и нажимает «Долгий отдых».
2. Приложение запрашивает подтверждение.
3. Восстанавливаются все ячейки заклинаний.
4. Сбрасываются временные боевые эффекты.
5. Восстанавливается реакция.
6. Пользователю предлагается изменить подготовленные заклинания.

Постусловие: ячейки всех уровней восстановлены до максимума; концентрация снята; активные эффекты с
длительностью короче отдыха закрыты; реакция доступна; бюджет магического восстановления заполнен
заново.
