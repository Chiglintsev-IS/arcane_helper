# Arcane Helper

Оффлайн-помощник для магического боя в настольной ролевой игре D&D 5e (редакция 2014).

Приложение не заменяет ни игрока, ни мастера. Оно ведёт игрока через применение заклинания: выбрать →
проверить возможность → объявить мастеру → определить броски → потратить ячейку → отслеживать эффект —
и держит всё, что для этого нужно знать о персонаже: ячейки, хиты, концентрацию, книгу, вещи, лист.

Носитель — iPhone: устанавливаемое PWA, полностью работающее без интернета. Единственный персонаж —
волшебник Торн.

## Как запустить

```bash
npm install
npm run dev              # разработка
npm run verify           # все проверки: документация, границы, типы, прогоны с покрытием, сборка
npm run verify:full      # то же плюс сценарии в браузере
npm run build            # статический экспорт в out/
```

## Как доставить на телефон

Приложение публикуется на GitHub Pages: push в `main` запускает работу `Pages`, она гоняет
`npm run verify` и выкладывает сборку. Адрес — <https://chiglintsev-is.github.io/arcane_helper/>;
на телефоне он ставится на домашний экран через «Поделиться».

Публикуется только проверенное: упавшая работа означает, что новой версии на адресе нет и на
телефон она не приедет. Что с последними публикациями — `gh run list --workflow=pages.yml`.

Приложение само ищет новую версию при запуске и при каждом возвращении в него, а найдя — показывает
полосу «Готово обновление.» с кнопками «Позже» и «Обновить».

Когда выкладывать наружу нечего или незачем, ту же сборку можно раздать только своим устройствам:

```bash
./scripts/serve-tailnet.sh   # собирает и раздаёт out/ внутри своей сети Tailscale
tailscale serve reset        # остановить раздачу
```

## Правовая заметка

Репозиторий не содержит и не должен содержать полные тексты коммерческих книг D&D. В приложении —
структурированные механические данные и тексты правил своими словами.
