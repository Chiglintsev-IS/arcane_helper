# Arcane Helper

Оффлайн-помощник для магического боя в настольной ролевой игре D&D 5e (редакция 2014).

Приложение не заменяет игрока и не заменяет мастера. Оно сопровождает игрока через полный
сценарий применения заклинания: выбрать → проверить возможность → объявить мастеру → отыграть →
определить броски → потратить ячейку → запустить и отслеживать эффект.

Первый носитель — iPhone: устанавливаемое PWA, полностью работающее без интернета.
Первый персонаж — Торн, волшебник 7 уровня.

## Как запустить

```bash
npm install
npm run dev              # разработка
npm test                 # модульные тесты движка правил и схем
npm run test:coverage    # тесты с порогом покрытия 100 %
npm run typecheck        # проверка типов
npm run check:docs       # целостность спецификации
npm run build            # статический экспорт в out/
```

## Как работать с репозиторием

Правила ведения кода и спеки описаны в [CLAUDE.md](CLAUDE.md). Главное правило: изменение

## Правовая заметка

Репозиторий не содержит и не должен содержать полные тексты коммерческих книг D&D. Подробности
и допустимые варианты работы с контентом — в разделе [Контент и право](docs/content.md#право).
