# Передача в разработку: Алхимия (книга + верстак)

## Что это

Экран «Алхимия» для мобильного приложения игрока настольной кампании «Сумрачный Доминион». Заменяет текущий экран `AlchemyScreen` (вкладки «Ингредиенты / Верстак / Справочник») на два режима: **Книга** (знание: виды, рецепты, правила) и **Верстак** (варка: состав, форма, сложность, партия).

## О файлах в этом архиве

`Alchemy.dc.html` — **дизайн-референс, а не продакшн-код**. Это HTML-прототип, показывающий верстку, состояния и поведение. Задача — воспроизвести эти экраны в существующей кодовой базе (Next.js + React + Tailwind, FSD-структура `src/ui/{app,screens,widgets,features,entities,shared}`), используя её токены и компоненты: `SURFACE_*` из `src/ui/shared/ui/surface.ts`, `RULE_*` из `rule.ts`, роли цветов из `src/app/globals.css`, шторки `Sheet`, поля `GrowingField` / `QuickAddField`. Инлайновые стили прототипа — следствие среды прототипирования; в приложении используйте классы и токены.

Прототип интерактивен: переключение набора оснащения, набор состава, форма состава, ограничения, партия, листание страниц книги, запись нового вида, дописывание полей вида.

## Точность

**High-fidelity.** Цвета, размеры, отступы и копирайт взяты из кода приложения и справочников мастера, воспроизводить можно один в один. Единственное сознательное отличие от прототипа: в приложении минимальный размер нажимаемой области задан глобально (`button { min-height: 44px }` в `globals.css`), в прототипе он проставлен инлайново.

## Источник правил

Два документа мастера (у заказчика):

1. **«Алхимия Сумрачного Доминиона · Справочник игрока»**, ред. 31.07.2026 — механика: направления, исследование, оснащение, разработка рецепта, время, расходники, партии, критические результаты, перечень эффектов.
2. **«Алхимические ингредиенты · Полевой справочник игроков»**, обновлён 13.09.2026 — 9 видов отряда: раскрытые свойства, СЛ поиска и сбора, выход в порциях, цены, особые реакции.

Все числа в прототипе сверены с этими документами и с доменным кодом (`src/core/domain/crafting/*`). Где правила и код расходятся, приоритет у правил: например, СЛ исследования в коде фиксирована номером свойства, а по правилам к ней добавляется модификатор редкости свойства.

## Модель данных и принципы

Три принципа, которые определили дизайн. Их нельзя нарушать при реализации:

1. **Приложение не знает мира.** Ни видов, ни мест, ни свойств оно не предлагает. Всё попадает в книгу со слов мастера. Поэтому нет фильтров по типу ингредиента и по биому, нет автоподстановки эффектов, нет поиска по каталогу.
2. **Книга — это книга.** Страницы книги не смотрят на наш набор оснащения, наши навыки и наш запас. Никаких «варим сейчас», «у нас нет владения», «в сумке 22». Состояние отряда живёт на верстаке и в общем экране «Вещи».
3. **Бросок и исход — за столом.** Приложение считает цену замысла (сложность, время, расходники, расход порций) и ничего не бросает. Ни ввода результата, ни критов, ни автосписания денег.

### Единица счёта

Всё в порциях. Выход сбора в справочнике мастера назван в порциях («1к6+1 порций с заросли», «4к20+40 порций с шара»), поэтому и собирают порции. Штук, граммов, остатков и долей порции в интерфейсе нет. Из чего состоит порция («10 зрелых листьев», «250 г мякоти») — свободная строка записи, ничего не пересчитывающая.

### Запас

Счёт запаса ведёт общий экран «Вещи» (`ThingsScreen`), у алхимии своей сумки нет. Верстак читает запас для проверки «хватает / не хватает», страница вида запас не показывает.

### Вид (запись книги)

```
{
  id, name,                    // имя со слов мастера
  props: [{ n: 1..4, name, dir }],   // раскрытые свойства; dir — направление алхимии
  foreign?: { number, dirRu }, // установлено направление свойства, но не сам эффект
  blockRu?,                    // почему исследование застопорилось
  findDc, gatherDc,            // СЛ Мудрость (Внимательность) / Интеллект (Травничество)
  yieldRu,                     // сколько порций даёт один сбор
  portionRu,                   // что такое порция, словами
  price, priceRu,              // базовая цена порции
  rarityRu, whereRu, specialRu // редкость источника, где искать, особые правила
}
```

Свежая запись: `props: []`, все числа неизвестны, поля дописываются по ходу игры.

### 5. Книга — раздел «Правила стола»

Назначение: свериться с механикой, не выходя из книги.

Три главы подряд, между блоками `gap: 22px`. Глава: заголовок 16 px / 600 `#d3ab5f` с `border-bottom: 3px double rgba(211,171,95,.45)` и вводная строка 11.5 px `#9c9280`. Метка блока внутри главы — 10 px `.14em` `#b4a78e`.

Быстрое раскрытие первого свойства (сырая проба / поверхностный анализ 10 минут СЛ 5). Надбавка за редкость свойства к СЛ исследования: обычное +0, необычное +1, редкое +2, очень редкое +4, легендарное +7 (строка с цветной меткой редкости слева). Чужое направление: непрофильными инструментами после половины времени узнают только направление реакции.

**Глава 2 · Варка зелья.** Цена замысла (база 10, ниже 5 не опускается, очистка +5, без профильного набора +5, ограничения не более −6). Цена эффекта по редкости — таблица «основной / дополнительный / подавить»: обычное +0 / +2 / +2, необычное +2 / +3 / +3, редкое +5 / +5 / +4, очень редкое +8 / +7 / +6, легендарное +12 / +10 / +8. Ступень совпадения: 2 вида — обычная +0, 3 — усиленная (≈×1,5) +3, 4 — концентрированная (≈×2) +6. Сколько варится партия: Сл 5–9 15 минут, 10–14 30 минут, 15–19 1 час, 20–24 2 часа, 25–29 4 часа, 30–34 8 часов, 35–39 16 часов, 40–44 32 часа, 45–49 64 часа, 50 и выше особый проект. Чем платим: Сл 5–19 обычные 1 зм/час, 20–29 очищенные 3 зм/час, 30–39 высокоточные 10 зм/час, 40 и выше экзотические 30 зм/час; комплект обслуживает до пяти рецептурных порций, платим за каждый начатый час. Сколько выйдет единиц: порции + ⌊порции / 4⌋ (1→1, 4→5, 8→10, 12→15, 20→25), бонусные единицы предел не занимают. Известный рецепт: после первого успеха повторяется без броска; формулу ломает смена вида, параметров, длительности, применения, очистки или недостаточное оснащение. Авария 1к6 (метка `#e4707f`): 1–2 реакция гаснет; 3 повреждён сменный элемент, ремонт 5% цены, до ремонта предел Сл на 5 ниже; 4 алхимик под действием случайного эффекта; 5 область радиусом 1 м; 6 и оборудование, и алхимик.

**Глава 3 · Оснащение.** Таблица «НАБОР / СЛ ДО / ПОРЦИЙ ЗА РАЗ»: обычный походный 15/3, надёжный походный 20/6, профессиональный походный 25/10, мастерский походный 30/15, базовый лабораторный 20/10, оснащённый 25/20, профессиональный 30/40, мастерский 35/80, великий 45/150, импровизированные сосуды 15/1 (+5 к сложности). Лабораторные помечены «стационарный». Сноска: без профильного набора +5 к сложности и вдвое меньшая партия; ремонт 5% цены, до ремонта предел Сл на 5 ниже.

- **Что в составе**: по каждому совпавшему свойству карточка `border-left: 4px solid` (акцент — основной эффект, `#8dc46e` — войдёт в состав, `#5c5347` — подавлено): имя 14.5 px / 600, источники 10.5 px `#9c9280`, роль 11 px / 600 цветом кромки, кнопки «Сделать основным» и «Подавить» (44 px). У подавленного раскрывается выбор редкости (+2 … +8) с подписью цены.
  - Если совпадений нет: абзац `border-left: 3px solid rgba(228,112,127,.5)` — «Совпавших свойств нет: пока нечего варить. Свойство входит в состав, если раскрыто хотя бы у двух видов».
- **Расход порций**: по каждому виду строка «нужно N порций из M» и статус «хватает» (`#8dc46e`) / «не хватает K» (`#e4707f`) с кромкой того же цвета.
- **Виды в состав**: карточки со свойствами (цветная полоса направления, номер слота, имя); свойство, которое совпадёт с уже взятым, подписано зелёным «совпадёт». Справа кнопка 44 × 44 «+» / «✓».
- **Редкость основного эффекта**: чипы «Обычное +0» … «Легендарное +12», выбранный — акцентная рамка и текст. Подпись: «Редкость называет мастер — от неё зависит и цена эффекта, и СЛ исследования».
- **Форма состава**: строки «параметр — значение — цена». Строка 48 px: точка-индикатор 6 × 6 (акцентная, если значение не стандартное), метка 11 px шириной 96 px, значение 13 px, модификатор 12 px / 600 (`#e79079` для плюса, `#8dc46e` для минуса), стрелка «▾/▴». Нажатие раскрывает варианты строками 44 px с ценой справа — текст не обрезается, переносится. Параметры и значения — дословно из правил: длительность, начало действия, цели и область, способ применения, сопротивление. Плюс «Повторы в полную силу» (шаговые −/+, +3 за повтор, максимум +12) и «Очистить смесь · +5» с предупреждением, что одно свойство нельзя снять и очисткой, и подавлением.
- **Ограничения**: восемь строк с ценой (−1 … −5), суммарно не ниже −6; у трёх непрозрачных формулировок серая подсказка с примерами. «Состав портится через 24 часа» и «через 1 час» взаимоисключающие — выбор одного снимает другое.
- **Партия**: строка «по N порций с каждого вида → выйдет M готового состава», под ней «за раз набор держит до 6 порций»; шаговые кнопки 44 px и число 26 px с подписью «порций заложено».
- **Из чего сложилась СЛ**: только ненулевые слагаемые (основа 10, основной эффект, дополнительные, ступень, форма, повторы, очистка, подавление, ограничения). Блок скрывается целиком, когда сложности нет.
- **Подвал** (2 строки + кнопка): «Проверка против 38» 12.5 px / 600 и справа «1к20 + Зельеварение + Инт» 10 px; предупреждение одной строкой `#e79079` («Выше предела набора (20) — только с разрешения мастера»); кнопка «Заложить партию» 46 px с подписью «спишет −2 порц. с вида · 16 часов · расходники 160 зм считает стол». Кнопка **не блокируется** при превышении предела (мастер может разрешить) — только предупреждающий вид: прозрачный фон, рамка и текст `#e79079`. Неактивна только когда варить нечего.

## Расчёт сложности

```
СЛ = max(5, 10
        + редкость основного эффекта            // 0/+2/+5/+8/+12
        + (число сохранённых эффектов − 1) × 2  // дополнительные, по их редкости
        + Σ ступень совпадения                  // 2 вида 0, 3 вида +3, 4 вида +6
        + Σ форма                                // длительность, начало, цели, применение, сопротивление
        + min(повторы × 3, 12)
        + (очистка ? 5 : 0)
        + Σ подавление по редкости               // не считается, если включена очистка
        + max(Σ ограничения, −6)
        + (без профильного набора ? 5 : 0))
```

Производные: время партии — по бенду итоговой СЛ; класс расходников — по бенду итоговой СЛ; цена расходников = ставка × начатые часы × ⌈порции / 5⌉; выход единиц = порции + ⌊порции / 4⌋; предупреждения — при СЛ > предела набора и при партии > предела набора.

СЛ исследования = базовая по номеру свойства (5 / 12 / 18 / 25) + модификатор редкости свойства (+0 … +7), который заранее неизвестен.

## Состояние

Верстак: состав (`compose: string[]`), форма (длительность, начало, цели, применение, сопротивление, повторы, очистка, подавленные свойства + их редкость, ограничения, основной эффект, его редкость), партия (число порций), выбранный набор оснащения, раскрытая строка формы.

Книга: открытый раздел, открытый вид, дописанные поля вида (`{ [id]: { findDc, gatherDc, yieldRu, portionRu, priceRu } }`), новые записанные виды, состояние формы записи.

Запас порций (`amount`) в прототипе локальный — в приложении это данные «Вещей».

Команды к домену (существующие в `src/contract/commands.ts`): `note_ingredient`, `reveal_property`, `drop_property`, `set_portion_size`, `add_item_note`, `craft_batch`, `set_workshop`. Новое, чего в контракте нет: дописывание СЛ поиска и сбора, выхода и цены у вида; выбор набора оснащения прямо с верстака; список известных рецептов.

## Что осталось за рамками

Сознательно не делалось, обсуждено с заказчиком:

- трансмутация и синтез ядов как рабочие направления (фокус на зельеварении; в интерфейсе они присутствуют только как записанное знание);
- экспериментальное смешивание втёмную (мастер считает совпадения тайно);
- перечень эффектов мастера как список выбора при записи свойства (мастер часто придумывает своё; максимум — справочная страница);
- критические результаты и авария как интерактив (остались правилом в справочнике);
- автоматическое списание денег (считает стол);
- сумка и деньги внутри алхимии (ведёт общий экран «Вещи»).
