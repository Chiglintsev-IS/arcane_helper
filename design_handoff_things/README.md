# Передача в разработку: Вещи (рюкзак, встречалось, покупки)

## Что это

Переработка экрана «Вещи» (`ThingsScreen`) для мобильного приложения игрока кампании «Сумрачный Доминион». Дополняет ранее переданный пакет по алхимии (`design_handoff_alchemy`).

Было: два уровня выбора до первой вещи («Рюкзак / Все вещи», затем пять категорий с переносом), полоса денег, три равновесные кнопки в каждой строке, статус словами («надето 1 · в сумке 0»).

Стало: три закладки — **Рюкзак · Встречалось · Покупки** — и карточка вещи страницей.

## О файлах в этом архиве

`Things.dc.html` — **дизайн-референс, а не продакшн-код**. Воспроизведите экраны в существующей кодовой базе (Next.js + React + Tailwind, FSD-структура `src/ui/{app,screens,widgets,features,entities,shared}`), используя её токены и компоненты: `SURFACE_*` из `src/ui/shared/ui/surface.ts`, `RULE_*` из `rule.ts`, роли цветов из `src/app/globals.css`, `Sheet`, `GrowingField`, `QuickAddField`, `StatPicker`. Инлайновые стили прототипа — следствие среды прототипирования.

Прототип интерактивен: фильтр по признакам, поиск, списание с отменой, надевание копий, правка карточки (название, признаки, прибавки, цена, заметки), отметка «хочу купить», покупка → вещь встаёт в рюкзак.

## Точность

**High-fidelity.** Цвета, размеры и копирайт взяты из кода приложения. Сознательные отличия: в приложении `button { min-height: 44px }` задан глобально в `globals.css`, в прототипе проставлен инлайново; `box-sizing: border-box` у полей в прототипе указан явно (в приложении даёт Tailwind preflight).

## Источник

Прочитаны и учтены: `ThingsScreen.tsx`, `Bag.tsx`, `ItemRow.tsx`, `StockControls.tsx`, `Purse.tsx`, `ItemBase.tsx`, `ItemSheet.tsx`, `StatPicker.tsx`, `entities/character/lib/labels.ts`. ## Модель: вещь как набор признаков

Ключевое решение, от которого зависит весь экран. **Категорий-папок нет.** У вещи есть признаки, и их может быть несколько одновременно — мифриловая кольчуга и экипировка, и ингредиент; магическая фокусировка и экипировка, и фокусировка.

```
{
  id, name,
  unit: "шт" | "комплект" | "порция",   // единица счёта
  bag, worn,                            // при себе / надето (worn ≤ bag)
  traits: ("wear" | "spend" | "alch" | "focus")[],
  bonuses: { [цель]: число },           // структурные прибавки, не текст
  prices: { "зм"?, "см"?, "мм"? },      // цена за одну штуку, любые номиналы
  notes: [{ id, textRu }],              // всё, что зависит от обстановки
}
```

Признаки (названия из `ItemSheet`): `wear` экипировка (золотой `#d3ab5f`), `spend` расходник (синий `#6fa9e2`), `alch` ингредиент (зелёный `#8dc46e`), `focus` фокусировка (сиреневый `#b98de8`). Признак решает и набор действий, и единицу счёта: `alch` считается в порциях и имеет алхимическую часть; `wear` даёт степпер надетых копий.

Три принципа:

1. **Число — общее свойство любой вещи.** «−/+» в каждой строке, единица своя. Ноль не скрывает строку.
2. **Прибавка — это цель и число, а не строка текста.** Выбор цели из списка (`StatPicker`), затем степпер. Нулевая прибавка снимается. Всё, что зависит от обстановки или требует броска («1к4 к Скрытности в болотах»), — заметка; в числа листа не входит.
3. **Знание об алхимии правят в алхимии.** В карточке вещи алхимическая часть показана фактами (раскрытые свойства, порция, СЛ поиска и сбора, выход) и переходом «Открыть в алхимии →». Раскрывать свойства здесь нельзя — там исследование, оснащение и СЛ.

## Экраны

Кадр 390 × 844 (iPhone 13/14). Колоночная вёрстка: фиксированная шапка, прокручиваемое содержимое (`flex:1; min-height:0; overflow-y:auto`), фиксированный подвал с одним действием.

### Общая навигация

Три закладки вверху каждого экрана: **Рюкзак · Встречалось · Покупки**, `min-height: 44px`, `gap: 4px`, активная — текст `#d3ab5f`, фон `#1e1a15`, рамка `1px solid #d3ab5f`; неактивная — текст `#9c9280`, фон `#2b251d`, рамка `rule-strong`. Нижней панели нет: экран вызывается из общей навигации приложения.

### 1. Рюкзак (`b1`)

**Шапка.** Строка 44 px: слева деньги (`7800 зм · 110 см`) — **нажатие по самой строке** раскрывает три поля номиналов (зм, см, мм), итог пересчитывается; справа, через волосяную линию, кнопка «признаки». Ниже поиск во всю ширину: «⌕ Найти вещь» с крестиком очистки.

**Фильтр признаков** (по кнопке «признаки»): чипы `border-radius: 22px`, 44 px — экипировка, расходник, ингредиент, фокусировка, плюс «хочу купить». Чип **трёхпозиционный**: первое нажатие — «только это» (золотая заливка, текст `#15120e`), второе — «кроме этого» (текст `#e79079`, рамка того же цвета, знак «✕» перед словом), третье снимает. Так решается «хочу всё кроме ингредиентов» одним нажатием.

**Строка вещи** (`min-height: 56px`, кромка слева 3 px — акцент у выбранной):

- имя 14 px, переносится (строка растёт в две-три строки);
- прибавки строкой `#b4a78e` 10.5 px: «+1 Класс Доспеха · +1 Все спасброски»;
- надетые копии золотым 10.5 px: «надето 2 из 5»;
- признаки серым 10 px: «экипировка · ингредиент»;
- число 19 px `tabular-nums` и единица 9.5 px: «48 порций», «12 комплектов», «1 шт»;
- «−» (акцентная, 46 px) и «+» (тихая, 46 px) через волосяные линии.

**Списание отменяемо.** После «−» снизу плашка: «Списано: Подорожник · Отменить» (`#2b251d`, кнопка акцентная). Это вместо подтверждений и вместо обратного «+1».

**Подвал.** «Записать вещь» раскрывается в поле «Название со слов мастера» (рамка акцентная) с «Отмена / Записать». Записанное сразу встаёт в список: просто вещь, число 1, без признаков.

### 2. Карточка вещи (`b4`)

**Страница, а не шторка** — её дописывают по ходу игры, и шторка с клавиатурой мешает. Шапка: «← Рюкзак», справа серым перечень признаков вещи («просто вещь», если их нет).

Блоки сверху вниз:

- **Название** — поле 48 px, правится прямо в нём.
- **Признаки** — пять чипов 44 px (экипировка, расходник, ингредиент, фокусировка, хочу купить), включённый — фон `group`, рамка и текст цветом признака. Снятие «экипировки» обнуляет надетое.
- **При себе** — степпер «− N +»; **Надето** — степпер, ограниченный числом при себе (кнопки гаснут на границах). Блок «Надето» показывается только у экипировки.
- **Прибавки** — строки «цель · − N +», знак у числа («+2», «−1»). Кнопка «Добавить прибавку» раскрывает список целей, сгруппированный как в `StatPicker`: числа листа (Класс Доспеха, Сложность спасброска врага, Попадание заклинанием, Инициатива, Пассивная внимательность, Заклинаний в подготовке, Бонус мастерства, Скорость) с подсказками из `statHint`, характеристики, спасброски, 18 навыков. Переключатель «действует надетой / действует при себе» (`worksCarried`).
- **Алхимия этой вещи** (только у признака «ингредиент», и заголовок печатается только когда есть записи): четыре слота свойств с цветом направления, строки «что такое порция», «СЛ найти», «СЛ собрать», «сбор даёт», и кнопка «Открыть в алхимии →».
- **Цена за одну штуку** — три поля номиналов в ряд (зм, см, мм), выравнивание по правому краю, `tabular-nums`.
- **Записано** — заметки; любая нажимается и правится на месте (поле + «Сохранить» / «Убрать»), ниже поле для новой.
- **Убрать вещь** — активна только когда `bag === 0 && worn === 0`, иначе притушена с причиной.

### 3. Встречалось (`b2`)

Вещи, которые есть в мире, но не в рюкзаке: видели у торговца, обещали, было и кончилось. Два состояния: «при себе» (зелёная кромка `rgba(141,196,110,.5)`, имя `ink`) и «нет при себе» (кромка прозрачная, имя `ink-soft`).

Строка: имя, состояние справа 10 px, ниже «где видели и за сколько» («видели у дварфа-торговца · около 4 000 зм», «обещал кузнец в Гнилом Броде»). Строка нажимается — открывает карточку, если вещь у нас есть. Справа кнопка 58 px «в покупки / в покупках».

Подвал: «Записать вещь» — та же кнопка, что в рюкзаке. Разницу задаёт наличие, а не две разные команды.

### 4. Покупки (`b3`)

Список, который заполняют по ходу игры, чтобы не забыть в городе. Источник — все отмеченные «хочу купить»: и записи из «Встречалось», и вещи из рюкзака (зелье кончилось — отметил прямо в карточке).

Шапка: «НУЖНО НА ВСЁ» и итог 24 px справа; под ним «в кошельке N зм · останется / не хватает M зм» (`#e79079`, если не хватает) и «K записей без цены». Кошелёк — тот же, что в рюкзаке: одно состояние на оба экрана.

Строка: галочка-отметка 22 px, имя, где видели, цена справа. Нажатие помечает купленным: имя гаснет, появляется зелёная «✓», сумма пересчитывается, **вещь встаёт в рюкзак** записью с числом 1 и заметкой «куплено по списку покупок».

Подвал: «Добавить в покупки».

Отступы: экран `12px`, строка `8px 12px`, между блоками карточки `12px` с `border-top: 1px solid rule`. Скруглений нет, кроме чипов фильтра (`22px`) — интерфейс бумажный.

Нажимаемое — минимум 44 × 44.

## Состояние

Список: активные фильтры признаков (`{ [признак]: "only" | "not" }`), строка поиска, выбранная вещь, раскрыт ли фильтр, раскрыты ли деньги, последнее списание для отмены.

Вещь: число при себе, надетые копии, признаки, прибавки, цена по номиналам, заметки, имя, отметка «хочу купить».

Общее: кошелёк по номиналам, отмеченные к покупке, купленные, записанные вручную вещи.

## Команды к домену

Существующие (`src/contract/commands.ts`): `add_item`, `set_item_stock`, `set_item_worn`, `set_item_kinds`, `set_item_price`, `add_item_note`, `drop_item_note`, `rename_item`, `drop_item`, `set_purse`, `want_item`.

Чего в контракте нет: трёхпозиционный фильтр по признакам (клиентский), отмена последнего списания, «купленное встаёт в рюкзак» одной операцией, признак «хочу купить» у вещи из рюкзака (сейчас желание живёт только в базе встреченного).

## Ассеты

Картинок и иконок нет. Знаки типографские: `⌕ ✕ ✓ − + → ←`.

## Файлы

- `Things.dc.html` — прототип: `b1` рюкзак, `b4` карточка вещи, `b2` встречалось, `b3` покупки. Внутри разметка и логика (фильтры, поиск, списание с отменой, надетые копии, прибавки, цена, заметки, покупки).

## Что осталось за рамками

- надевание и класс доспеха в листе персонажа (в рюкзаке только счёт копий — по решению заказчика КД здесь не место);
- быстрый пояс частых расходников (пробовали, убрали как лишний слой);
- вес и грузоподъёмность;
- свайп-действия на строке (вместо них «−/+» и карточка).
