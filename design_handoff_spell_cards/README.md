# Handoff: Карточки заклинаний и действий — экран «Игра»

## Overview
Редизайн карточек заклинаний / простых действий в списке на экране «Игра» (мобильный, тёмная тема). Цель: убрать «суп» одинаковых чипов-рамок (Действие / Ритуал / Концентрация / Без броска / компоненты / категория) и заменить его системой фиксированных строк, где у каждого свойства своё место и свой визуальный канал. Итоговый формат согласован с владельцем продукта (раунд 8, вариант 8a в референсе).

## About the Design Files
Файл `Spell Cards.dc.html` — **дизайн-референс в HTML**, а не производственный код. Это канвас со всей историей итераций; **финальный согласованный дизайн — верхняя секция «8», карточка 8a** (список всех 33 действий). Задача — воспроизвести этот дизайн в существующем коде приложения (arcane_helper) его собственными компонентами и паттернами. Секции 1–7 — история решений, их реализовывать не нужно.

## Fidelity
**High-fidelity.** Цвета, размеры, отступы и формулировки — финальные, воспроизводить точно (шрифт можно заменить на шрифтовую пару приложения, сохранив роли «обычный/моно»).

## Информационная модель карточки
Источник данных — JSON заклинаний (поля `castingTime`, `range`, `area`, `targeting`, `components`, `duration`, `concentration`, `ritual`, `resolution`, `damage`, `combatRole`, `level`). Порядок строк карточки фиксирован:

1. **Заголовок**: название (17px/700, #f0e6cd) + справа компоненты.
2. **Строка каста**: `[тип каста цветом] · [цена]`, справа — «держится».
3. **Триггер** (только реакции): своя строка.
4. **Куда**: дальность · область · цель, одной серой строкой.
5. **Эффект**: белые жирные строки и/или блок броска с исходами.
6. **Примечание**: серая строка (опционально).

### Правила по каждому свойству
- **Тип каста** = будущие фильтры; единственный «сильный» цвет карточки:
  - `● Действие` #6fa8e8 · `◆ Бонусное действие` #e8964f · `↺ Реакция` #e8a2e0 · `◔ 1 минута` #b3a682.
  - Строка каста не переносится (`white-space: nowrap` на левой части).
- **Цена** (серым #9a8f74 после « · »): `бесплатно` (заговор) · `ячейка N` · `ячейка от N ↑` (растёт от старшей ячейки) · `ячейка N + пыль 25 зм` · `ячейка N или ◈ ритуал` (без «+10 минут» — игроки это знают) · `руна N/M` · `заряд N/M`. Уровень и школа НИГДЕ не показываются отдельно — цена и есть уровень.
- **Держится** (правый край строки каста): `1 раунд`, `8 часов`, `пока не рассеют` — #cdbfa0/600; с концентрацией — `◉ 10 минут` #5fc9b0/600. Мгновенные эффекты — ничего не выводить (не «—»). Никаких чипов «Концентрация»; не писать «пока держите концентрацию» в примечаниях.
- **Триггер реакции**: своя строка сразу под строкой каста, цвет реакции с opacity 0.8, формат «когда …» (напр. «когда в вас попали атакой»). 13px.
- **Куда** (12.5px #9a8f74): `60 футов · 1 существо`, `касание · согласное существо без доспехов`, `конус 30 футов от себя — задевает и своих`, `на себя · чутьё в сфере 30 футов`.
- **Компоненты** (справа от названия, mono 10px #b3a682, letter-spacing 0.1em): только нужные, буквами `Г·Ж·М`. Нет компонентов — ничего. Текст материала — только в раскрытии карточки.
- **Категория/роль** (`combatRole`): цветная полоска слева 3px, без слова: offense #e35d6a · defense #56c4cf · other #8d8267.
- **Бросок** (янтарь #d9a441/600, 13px): всегда назван бросающий: «⚄ Цель бросает спас ЛОВ против КС 16», «⚄ Каждый в конусе бросает спас ТЕЛ против КС 16», «⚄ Атака d20+8 по КД цели». Уточнение броска — своя строка под ним, тот же янтарь с opacity 0.7, 12.5px («преимущество, если цель в металлических доспехах», «согласная цель — без броска», «повтор спасброска в конце каждого её хода»). «Без броска» не выводится вовсе.
- **Исходы**: подписанные строки с подписью-меткой слева (mono 9px #6b634e, колонка 52px, выравнивание вправо):
  - `ПОПАЛ` → белый жирный (#f0e6cd/600)
  - `ПРОВАЛ` → белый жирный (#f0e6cd/600)
  - `УСПЕХ` → серый (#9a8f74/400)
  - Каждый пункт исхода — отдельная строка (не клеить через «·» в одну). 13.5px.
- **Эффект без броска**: белые жирные строки 14px/700 (#f0e6cd), по одному пункту на строку («+2 КД» / «×2 скорость» / «доп. действие каждый ход»).
- **Примечание** (12.5px #9a8f74): отдельной строкой, полными предложениями, БЕЗ приёма «белый текст — тире — серый хвост».
- **Вычисленные значения персонажа** обязательны там, где есть: КС 16, атака d20+8, «КД 22 вместо 17», кости заговоров по уровню персонажа (2d8 на 7-м). Эти числа приложение уже умеет считать — сохранить.
- **Простые действия** (не заклинания, напр. «Последняя подсказка»): та же карточка; цена — `заряд 1/1`, компоненты и «держится» просто отсутствуют, каст может отсутствовать.

## Группировка списка
Секции по типу каста (= фильтры), в порядке: `● ДЕЙСТВИЕ · 26` → `◆ БОНУСНОЕ ДЕЙСТВИЕ · 1` → `↺ РЕАКЦИЯ · 4` → `◔ ВНЕ БОЯ — КАСТ ОТ 1 МИНУТЫ · 2`. Заголовок секции: mono 10.5px, цвет типа каста, letter-spacing 0.14em, с количеством. Внутри секции — по возрастанию цены. Липкой шапки-таблицы НЕТ (сознательно отвергнута), колонок-таблиц НЕТ — консистентность держится порядком строк и цветом.

## Чего в новом дизайне НЕТ (удалить из текущего UI)
- Чипы-рамки «Действие / Ритуал / Концентрация / Без броска».
- Слова «голос · жест · материал» в шапке карточки.
- Чип категории («× Другое», «+ Боевое», «◇ Защита») — заменён полоской.
- «Мгновенный эффект», «Без ячейки», школы магии, уровень отдельным элементом.
- Подпись «ритуал 11 минут / +10 минут».
