# Источники стола

Тексты, полученные от мастера. Это не документация проекта: здесь лежит то, **из чего** берутся
числа, а не то, как приложение с ними работает. Работа приложения описана в `docs/`.

Стол играет не по классическому D&D: часть механик — домашние, и другого их описания, кроме этих
файлов, не существует. Общедоступные правила их не содержат, вывести по образцу нельзя.

## Правило работы с источником

Числа берутся отсюда дословно. Там, где источник молчит, приложение молчит тоже: догадка о правиле
— вопрос мастеру, а не строка в коде. Справочник по алхимии прямо
говорит, что не содержит ни описаний отдельных ингредиентов, ни механики конкретных эффектов, — и
приложение поэтому считает сложность, время, расходники и партию, но не результат состава.

Справка по магии называет заклинания русскими именами, и часть из них многозначна: одно и то же слово
носят разные заклинания разных кругов. Имя из справки сверяется со страницей источника правил, прежде
чем стать записью в реестре запретов, — иначе запрет ложится не на то заклинание. Правовой режим сам
приложением не моделируется: три категории допуска — предмет разговора с мастером, а запрет попадает
в реестр только тогда, когда решение стола уже принято.

Новая редакция кладётся сюда с обновлённой датой в таблице выше. Расхождение старой и новой
разбирается как правка правил: числа в коде меняются вместе с документом контекста в `docs/`.
