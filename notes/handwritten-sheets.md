# Записи с листов (рукописные)

Дословный перенос рукописных заметок с девяти листов, снятых на фото. Перенесено 31 августа 2026.
Ничего не дополнено, не исправлено и не истолковано: где почерк не читается, стоит помета, а не
догадка.

Обозначения:

- `[?]` — чтение неуверенное;
- `[…]` — строка обрезана краем листа или кадром;
- `[неразборчиво]` — прочитать не удалось;
- ~~зачёркнуто~~ — зачёркнуто на листе;
- `(обведено)`, `(подчёркнуто)` — как на листе.

## Лист 1 — «Храм в болотах»

```
Храм в болотах.
Яйца редкого животного
```

Схема в две-три группы, справа налево:

```
                              свер х.            ядоъ.
              стихии.          ↳ психика
   физ.        ↳ огонь         ↳ св.магия.
   др.         ↳ холод
   кол
   реж
   кислота
```

Обведено одной линией (три строки, между второй и третьей — знак `+`):

```
ог.  красивый кусок корешка  -  [?]
ог.  красивый кусочек болотного камня.
                     +
ог.  красивая палка в виде посоха.
```

```
+ 1. подорожник.            (1 подчёркнуто)
```

```
На фреска        в храме при прикосновении опи[…]
вибрируют, слабая вибрация
~~[неразборчиво] — 1 длин. — 1 длин[…]~~
```

```

```

```
[…]иппал [?]  Верёвка.
```

```

```
